# 💻 CNX-JobHub | Premier IT Job Board Platform

แพลตฟอร์มหางานสายไอที (Job Portal) ที่ออกแบบมาเพื่อ Tech Community ในเชียงใหม่โดยเฉพาะ เน้นความเร็วและประสิทธิภาพสูง 

## ✨ ฟีเจอร์เด่น
- **Lightning-Fast CRUD:** ระบบจัดการข้อมูล (เพิ่ม/ลบ/แก้ไข) ทำงานผ่าน LocalStorage ทำให้หน้าเว็บไม่ต้องรีโหลด (Zero lag) 
- **Smart Data Filtering:** อัลกอริทึมกรองข้อมูลแบบเรียลไทม์ ผู้ใช้สามารถค้นหางานตามเงื่อนไขเงินเดือนและทักษะได้อย่างรวดเร็ว 

## 🛠️ Tech Stack
- **Framework:** Next.js 
- **Language:** TypeScript 
- **Styling:** Tailwind CSS
- **State Management:** LocalStorage
